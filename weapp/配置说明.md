# 臻瓷汇 · 配置说明

本项目是「会员制瓷砖产品小程序」，基于 **ColorUI + 微信云开发**。
按本文顺序操作即可从零跑起来。

- 小程序代码：`weapp/miniprogram/`
- 云函数：`weapp/cloudfunctions/`
- 全局配置：`weapp/miniprogram/config.js`

> 技术栈：原生小程序 + 云开发（云函数 `api` 统一数据入口 + 云数据库 + 云存储）。
> 价格不下发到前端云数据库直连，只由云函数按当前会员等级返回，避免被批量抓取。

---

## 1 准备工作

1. 一个已注册的**小程序**账号（个人主体也可以，但**视频号内嵌播放**建议企业主体，见第 8 节）。
2. 微信开发者工具（建议最新稳定版）。
3. 小程序的 **AppID**：微信公众平台 →「开发管理 → 开发设置 → 开发者 ID」。

---

## 2 导入项目

1. 打开微信开发者工具 →「导入项目」。
2. **目录**选择 `weapp` 文件夹（即包含 `project.config.json` 的那一层）。
3. **AppID** 填你自己的 AppID。
4. 导入后确认工具左下角「详情 → 本地设置」中 **ES6 转 ES5**、**增强编译** 已勾选（项目已默认开启）。

---

## 3 开通并配置云开发

1. 开发者工具顶部点击 **「云开发」** → 开通（选择按量付费的免费额度即可）。
2. 创建一个环境，记下 **环境 ID**（形如 `zhenci-tile-3g8xxxxx`）。
3. 打开 `weapp/miniprogram/config.js`，填写环境 ID：

```js
module.exports = {
  // 只有一个环境时可留空，会自动使用默认环境
  envId: 'zhenci-tile-3g8xxxxx',
  ...
}
```

同时可在此文件修改：品牌名 `brand.name`、英文副标题、客服微信号 `brand.serviceWx`、以及对外的版本号 `brand.version`。

---

## 4 部署云函数

在 `cloudfunctions` 目录下共 3 个云函数，**逐个**右键 →「上传并部署：云端安装依赖」：

| 云函数 | 作用 | 何时需要 |
| --- | --- | --- |
| `api` | 全部业务接口（会员、邀请码、产品价格、内容、投票、关联小程序） | 必须 |
| `initdb` | 一键创建数据库集合 + 写入演示数据 | 首次部署执行一次 |
| `login` | 获取 openid（备用，业务已由 `api` 内部处理） | 可选 |

> 部署 `api` 前请确认 `cloudfunctions/api/package.json` 中已依赖 `wx-server-sdk`（项目已内置）。

---

## 5 初始化数据库与演示数据

1. 云开发控制台 →「云函数」→ 找到 `initdb` →「测试」→ 直接执行（不需要参数）。
2. 执行结果会返回创建/写入明细。它会：
   - 创建全部集合（已存在则跳过）；
   - 空集合写入演示数据（瓷砖产品、首页视频/图文、品牌小程序、投票、3 个演示邀请码）；
   - **已有数据的集合不会被覆盖**。
3. 想重置演示数据（会员与邀请码保留）：测试时传 `{ "reset": true }`。

演示邀请码（仅演示，建议上线前作废）：

| 邀请码 | 等级 |
| --- | --- |
| `PT8A0001` | 普通会员 |
| `GJ8B0002` | 高级会员 |
| `HX8C0003` | 核心会员 |

## 6 设置管理员

管理后台入口在 **「我的 → 管理后台」**，只对管理员显示。

**首次部署的引导机制**：`admins` 集合为空时，**第一个访问小程序的用户会被自动设为管理员**（云函数日志会打印其 openid）。

- 验证：进入「我的」页，若出现「管理后台」入口即成功。
- 想更换/增加管理员：云开发控制台 →「数据库 → `admins`」→ 新增一条 `{ "openid": "对方openid", "name": "备注" }`；要取消某人的管理员，删除对应记录即可。
- 获取 openid：让对方打开「我的 → 我的 openid」复制，或看云函数日志。

> 注意：自动引导只在集合为空时触发一次。上线前请固定好管理员记录。

## 7 数据库集合说明

| 集合 | 用途 | 关键字段 |
| --- | --- | --- |
| `admins` | 管理员白名单 | `openid` |
| `members` | 会员 | `openid`、`nickname`、`avatar`、`level`(0/1/2)、`status`(active/disabled)、`code` |
| `invite_codes` | 邀请码（一码一会员） | `code`、`level`、`remark`、`status`(unused/used/void)、`usedBy`、`usedByOpenid`、`usedAt`、`expireAt` |
| `contents` | 首页内容 | `type`(video/article)、`title`、`cover`、`feedId`、`finderUserName`、`feedToken`、`images`、`body`、`pinned`、`sort`、`status`(on/off) |
| `products` | 产品与三档价格 | `no`(唯一)、`brand`、`name`、`spec`、`cat`、`unit`、`prices[3]`、`images`、`desc`、`off` |
| `mini_apps` | 关联品牌官方小程序 | `name`、`appid`、`path`、`logo`、`sort` |
| `votes` | 投票 | `title`、`intro`、`images`、`options[]`、`counts[]`、`voted`、`deadline`、`deadlineText`、`doing` |
| `vote_records` | 投票记录（每人一票） | `_id` = `投票id_openid`、`voteId`、`openid`、`option` |

**权限建议**：这些集合的「数据权限」全部保持默认的 **「仅创建者可读写」/「所有用户不可读写」** 即可 —— 前端不直连数据库，全部经由云函数访问，云函数拥有完整权限。

## 8 首页视频配置（引用视频号）

首页内容支持两种：**视频（视频号内嵌）** 和 **图文（站内发布）**。视频**不在小程序内托管**，而是引用你视频号里已发布的视频。

### 8.1 前置条件

1. 视频必须**先发布到你的视频号**，且为**视频类型动态**。
   - ⚠️ **纯图片类型的视频号动态不支持内嵌播放。**
2. 主体要求：`channel-video` 组件要求小程序与视频号**同主体或关联主体**。
   - 基础库 2.31.1 起，**非个人主体**小程序可放宽到非同主体，但需要 `feed-token`，且不建议依赖。
   - 因此：**建议小程序为企业和非个人主体，且与视频号主体一致**，这也是原需求中「先发视频号再引用」的原因。
3. 基础库需 ≥ 2.31.1（本项目 `libVersion` 已设为 3.5.5）。

### 8.2 获取参数

在**视频号助手**（channels.weixin.qq.com，需用管理员微信扫码登录）中找到目标视频：

| 参数 | 说明 |
| --- | --- |
| `feedId` | 目标视频的动态 id，**必填** |
| `finderUserName` | 你的视频号账号 id（视频号主页对应的 finder id） |
| `feedToken` | 仅**非同主体**播放时需要的临时 token |

> `feedId` / `finderUserName` 的具体取值位置以**微信官方文档《channel-video 组件》**的说明为准（该字段未在视频号助手界面直接展示，需按官方指引获取）。
> 本项目的**兜底方案**：若内嵌播放不可用，详情页内置了「**在视频号中打开**」按钮（`wx.openChannelsActivity`），可直接跳转视频号播放，此方式无主体限制。

### 8.3 在小程序里配置

管理后台 →「内容管理」→「新建视频」，填写：

- **标题**、**摘要/简介**、**来源文案**（如「视频号」）
- **封面图**（建议 16:9，点击上传，会存到云存储）
- **feedId**（必填）、**finderUserName**、**feedToken**（非同主体时填）
- **时长文案**（如 `03:12`，仅为展示）
- 「置顶展示」开关：**打开即固定为首页第一条**（用于那条功能介绍视频）

保存后，会员/游客打开首页即可看到；点击进入详情页内嵌播放。

### 8.4 排序与上下架

- **上移 / 下移**：调整首页顺序（置顶内容固定在首位，需先取消置顶才能与普通内容换位）。
- **置顶 / 取消置顶**：切换固定首位。
- **上架 / 下架**：关闭后会员端不可见（后台仍保留）。
- 视频号原视频被删除时，小程序内该条会显示「**视频已失效**」，请管理员在后台下架或删除该条目。

## 9 图文内容配置

管理后台 →「内容管理」→「新建图文」：

- 填写标题、摘要、来源，上传封面；
- 填写**正文**（支持换行分段，正文按空行/换行分段展示）；
- 上传**配图**（最多 9 张，未单独上传封面时列表封面默认取第一张配图）。

图文详情在小程序内直接阅读，不依赖视频号。

## 10 关联品牌官方小程序

管理后台 →「关联小程序」→ 填写：

- **名称**（如「马可波罗瓷砖官方」）
- **AppID**（`wx` 开头的 18 位，从对方小程序或其管理后台获取）
- **跳转路径**（选填，留空进对方首页）
- **Logo**（选填，建议正方形）

保存后展示在「产品库」页顶部横滑区域，会员点击即跳转。目标小程序需**已发布上线**；跳转失败请核对 AppID。

## 11 邀请码与会员

### 11.1 生成

管理后台 →「邀请码管理」→ 选择**绑定等级** + 备注（发给谁）+ 有效期（天，留空长期有效）→ 生成。

- 邀请码为 8 位随机大写字母数字。
- **一码一会员**：每个码只能成功开通一次，用过的码无法再用。
- 列表可看到完整追溯链：生成时间、备注、是否已使用、使用者昵称、开通时间。
- 未使用的码可「作废」；已使用的码不能作废（只会展示痕迹）。

### 11.2 会员开通

会员打开小程序 →「我的」→ 填写昵称/头像 + 输入邀请码 → 开通成功，自动绑定该码预设等级。

校验规则（任一不通过都会给出明确提示）：

| 情况 | 提示 |
| --- | --- |
| 码不存在 | 邀请码不存在，请核对后重试 |
| 已作废 | 该邀请码已作废 |
| 已被使用 | 该邀请码已被使用 · 一码一会员 |
| 已过期 | 该邀请码已过期 |

### 11.3 会员等级

等级默认为 **普通 / 高级 / 核心** 三级，**只影响价格展示**，不影响其他功能。

- 名称可在 `weapp/miniprogram/config.js` 的 `levels` / `levelsShort` 中修改（下标即等级，需与数据库 `level` 数值对应）。
- 停用会员：云开发控制台把 `members` 中该记录的 `status` 改为 `disabled`，其权限等同游客。

## 12 价格设置

管理后台 →「价格设置」：

- **新增产品**：填写编号（唯一，如 `A-8001`）、品牌、名称、规格、分类、单位、**三档会员价**、说明、图片、是否上架。
- 列表可直接**行内改三档价格** → 点该行「保存价格」；或点顶部「保存全部价格」批量保存。
- 支持「编辑资料」「上架/下架」「删除」。
- 会员端只会拿到**自己等级**的那一档价格，其余两档不下发。

查价：会员输入产品编号即可看到本等级价格；编号不存在提示「未找到该产品，请核对编号」，已下架提示「该产品已下架」。

---

## 13 投票

管理后台 →「投票管理」→「发起投票」：

- 标题（必填）、说明、新品图片（最多 6 张）
- **选项 2~4 个**（可增删）
- **截止时间**（选填，留空长期有效；截止当日 23:59 自动停止）

会员投票规则：**每人限投一票、不可改票**；投票后可见各选项实时占比；截止后结果继续可见。
可在列表点「投票明细」查看谁投了什么（仅管理员可见）。

分享：投票详情页支持转发到**微信群**（小程序卡片）和**分享到朋友圈**（朋友圈打开为单页模式，需进入小程序参与投票）。分享出去的页面不含任何价格信息。

## 14 合法域名与上线前检查

1. **图片域名**：演示数据里的图片是外部 https 图片。正式上线前请在微信公众平台「开发管理 → 开发设置 → **服务器域名 → downloadFile 合法域名**」加入该图片域名；**更推荐**：把所有图片改为后台上传到**云存储**（云存储域名已自动放行，无需配置）。
   - 开发阶段可在开发者工具「详情 → 本地设置」勾选「不校验合法域名」临时跳过。
2. **tabBar 图标**：`weapp/miniprogram/images/tab/` 已内置 5 组图标（`home/grid/tag/vote/mine` 及选中态 `-on`），如需替换请保持同名同尺寸（建议 81×81px）。
3. **前端不直连数据库**：所有读写走云函数 `api`，无需额外配置数据库权限；请勿把集合权限改成「所有用户可读写」。
4. **上线前建议**：
   - 作废/删除演示邀请码（`PT8A0001`/`GJ8B0002`/`HX8C0003`）；
   - 替换演示产品与内容为真实数据；
   - 核对 `admins` 集合里只有你自己的 openid；
   - 在「我的」页确认 `brand.serviceWx` 客服微信号正确。
5. **合规提示**：`wx.getUserProfile` 等旧的昵称头像接口已收紧，本项目使用官方的「头像昵称填写能力」（`open-type="chooseAvatar"` + `type="nickname"`），无需额外申请。

## 15 常见问题

**Q1 打开小程序报「云函数未部署或网络异常」**
`api` 云函数未部署，或 `config.js` 里的 `envId` 与环境不一致。重新「上传并部署：云端安装依赖」并核对环境 ID。

**Q2 首页视频提示「该视频尚未配置视频号参数」**
该条内容没填 `feedId`。到「内容管理 → 编辑」补填。

**Q3 视频提示「视频已失效」**
视频号原视频被删除或设为不可见，或主体不匹配。请在后台更新该条目，或使用详情页的「在视频号中打开」。

**Q4 会员看不到产品库/查价**
产品库和查价仅对会员开放，未开通时会显示锁屏引导。先用邀请码开通。

**Q5 价格想改成两档或四档**
三档对应 `config.js` 的 `levels` 数组和数据库 `prices` 数组。改档位数需要同步修改 `config.js`、`products.prices` 长度，以及管理端「价格设置」的输入框数量（当前为 3 档写死）。

**Q6 想新增一位管理员**
见第 6 节：在 `admins` 集合新增其 openid 记录。

**Q7 测试时想重置演示数据**
云开发控制台 → `initdb` → 测试，参数填 `{ "reset": true }`（会员、邀请码、投票记录不会被清空）。
